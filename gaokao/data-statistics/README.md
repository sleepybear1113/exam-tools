# 高考及 1 月学选考报名数据统计工具

浏览器本地统计工具：把 Excel 拖入对应区域，程序读取、过滤审核状态、按身份证去重、与缴费信息交叉比对，并生成多张 HTML 统计表。**所有数据只在浏览器内存中处理，不上传任何服务器。**

## 1. 运行方式

直接双击 `index.html`，用最新版 Chrome 或 Edge 打开即可（`file://` 方式可用，不需要 Node.js、npm 或任何构建工具）。

页面依赖仓库内已有的本地库，无需联网：

| 用途 | 文件 |
|---|---|
| Vue 3（Global Production 构建） | `../../lib/vue/3.5.20/vue.global.prod.js` |
| SheetJS Community Edition **完整版** 0.20.3 | `../../lib/sheetjs/0.20.3/xlsx.full.min.js` |

注意：

- 读取 `.xls`（BIFF）必须使用完整版 `xlsx.full.min.js`，**不要替换为 `xlsx.mini.min.js`**。
- 如需改用 CDN，只替换 `index.html` 中两个 `script` 的 `src`，业务 JS 无需修改。
- 业务脚本使用普通 `<script>` 顺序加载，未使用 `type="module"`，因此可以直接以本地文件方式运行。

## 2. 四个上传区域对应的文件

| 上传卡片 | 接受扩展名 | 业务含义 | 必要字段 |
|---|---|---|---|
| 高考报名信息 | `.xlsx` | 高考报名人数、术科分类人数、特招生测试人数 | `SHZT_`、`BMD_`、`SFZH_` |
| 高考报名缴费信息 | `.xls`（兼容 `.xlsx`） | 按报名点统计各缴费项目已缴/未缴人数，并与报名信息交叉比对 | `缴款单号`、`证件号码`、`缴款状态`、`项目编号` |
| 1月学选考报名信息 | `.xlsx` | 语文、数学、外语各语种及各选考/学考科目人数 | `SFZH`、`BMD`、`SHZT` |
| 单独考试报名信息 | `.xlsx` | 按报名点及县区统计总人数与各报考类别（`BKKL_`）人数 | `BMD_`、`BKKL_` |

`1月学选考报名缴费信息` 本期不处理，页面上没有对应上传区域。

- 文件必须拖入（或点击选择）对应区域；放错区域会提示“文件类型不匹配 / 未识别到表头”，不会误解析。
- 每张卡片可单独替换、移除文件，替换不会与新文件合并。
- 表头可以在前 20 行内的任意位置；存在多个可用工作表时会显示工作表选择框。

## 3. 报名点与县区映射

两个独立面板，均为可编辑的两列表格（代码 / 名称）：

- **新增一行**：手工录入。
- **批量导入**：在文本框粘贴两列数据（Tab 或逗号分隔，每行一条），或直接粘贴 `{"代码": "名称"}` 形式的 JSON，再点击“解析导入”。
- 重复代码会标红并在异常区提示，统计时仅第一条生效。
- 代码按字符串处理，不会丢失前导零；报名点代码为纯数字且不足 5 位时自动左补零。
- 县区代码取报名点代码第 2–3 位（`code.slice(1, 3)`）。
- 映射表保存在 `localStorage`（键：`exam-data-statistics:bmd-map:v1`、`exam-data-statistics:county-map:v1`），**只保存代码与名称**，不保存任何考生信息。
- 未配置的代码仍保留在统计结果中，名称显示“未配置名称”，并在异常区列出。
- 面板默认状态：**已有映射数据时自动收起**（摘要行显示条数），**暂无数据时自动展开**，方便首次录入。

## 4. 统计口径要点

固定口径（页面不提供可配置项）：

- **审核状态**：报名信息仅保留 `3`、`"3"`、`审核通过`；缴费文件没有审核状态列时不做审核过滤。
- **主键**：身份证号码（末位 `x` 统一转大写）；空身份证、数值精度丢失的身份证不参与统计与匹配。
- **去重**：同一身份证同一报名点只计 1 人，术科/科目标记合并；同一身份证跨报名点视为冲突，默认排除。
- **术科类别**：`YSTYSK_` 按 `|` 拆分，完整代码精确匹配（30/31/32/33/34/36/39/41）。
- **特招生测试**：`CJTZSCS_` 去首尾空格后严格等于 `1` 才计数。
- **缴费报名点**：取缴款单号第 18–21 位为后四位，第 22–23 位映射首位（≤12→8，13–50→9，>50→7）。
- **缴费项目**：取项目编号最后一个下划线后的内容，不区分大小写（pt/cm/ms/sf/szby/ty/wd/yy）。
- **缴费状态**：`已缴款`=已缴费；`待缴款`、`未缴款`=未缴费；其他值为未知状态，不擅自归类。
- **缴费表总人数**：普通类（`pt`）的去重身份证人数，不区分缴款状态。
- **交叉过滤**：缴费文件中完全没有该身份证记录 → 视为已缴费；普通类未缴款或缺普通类记录 → 不纳入报名总人数；普通类已缴款但某术科对应项目未缴费 → 仍计总人数，但不计该术科人数；戏曲类（39）不要求缴费项目。
- **单独考试类别**：`BKKL_` 即报考类别，纯数字不足两位自动补零（`1` → `01`）；取值为 `17` 且 `QTLZY_` 命中已知代码（1/2/4/5/6/7）时拆分为 `17-1`～`17-7` 各列，其余情况使用 `BKKL_` 原值。统计表列标题统一为"代码 + 中文"（如 `01 机械类`、`17-2 体育`），代码含义见 `DANDU_CATEGORIES`。
- **单独考试可选字段**：文件含 `SHZT_` 时仅统计审核通过记录；含 `SFZH_` 时按身份证去重，同一人同一类别只计 1 人，跨报名点冲突排除；两个字段缺失时分别退化为不过滤、按行计数，并在结果表备注中提示。

## 5. 页面结构

```text
gaokao/data-statistics/
├─ index.html                 # 页面模板（Vue 挂载点）
├─ css/style.css              # 独立样式，无 CSS 框架
├─ js/
│  ├─ excel-reader.js         # 文件读取、工作表扫描、表头识别、Schema 定义
│  ├─ data-normalizer.js      # 字段标准化、四类文件解析、异常收集
│  ├─ statistics-gaokao.js    # 高考报名统计 + 缴费交叉过滤
│  ├─ statistics-payment.js   # 高考缴费独立统计
│  ├─ statistics-january.js   # 1月学选考统计
│  ├─ statistics-dandu.js     # 单独考试报名统计
│  └─ app.js                  # Vue 页面：上传、映射、生成、渲染
└─ tests/
   ├─ statistics.test.cjs     # 构造数据验证统计口径
   ├─ reader.test.cjs         # 生成真实 xlsx/xls 验证表头识别
   └─ sample.test.cjs         # 用 sample/ 下真实样本跑完整流程（样本缺失时自动跳过）
```

每张统计表右上角提供“复制表格”按钮：按 Tab 分隔复制表头、数据行与合计行，可直接粘贴到 Excel 形成表格（空值输出为空单元格）。

每个统计类型下方有“隐藏合计为 0 的列”选项：勾选后，合计值为 0 的统计列不显示，代码/名称列始终保留，字段缺失的列也保留（避免被误认为 0）。该选项只影响表格显示与复制内容，不改变统计结果；勾选后表格右上角会提示已隐藏的列数。

## 6. 自测

```bash
node gaokao/data-statistics/tests/statistics.test.cjs   # 构造数据：统计口径与边界
node gaokao/data-statistics/tests/reader.test.cjs       # 生成真实 xlsx/xls：表头识别
node gaokao/data-statistics/tests/sample.test.cjs       # 真实样本：完整流程与一致性校验
```

覆盖内容：报名点代码补零/超长、缴款单号位置解析与 12/13/50/51 边界、术科拆分、特招生判定、缴费状态归一、审核过滤、跨报名点冲突排除、缴费交叉规则（无记录视为已缴、普通类未缴排除、术科未缴只影响该类别、戏曲类不受影响）、缴费统计列顺序与总人数口径、1月学选考语种与科目分列、单独考试报考类别细分（17→17-x）与县区汇总。

`sample.test.cjs` 会读取 `sample/` 下的三个真实导出文件，只输出表头、数量、取值分布与统计表规模，**不输出姓名与身份证号码**；样本目录不存在时自动跳过。

`sample/` 内为敏感数据，请勿提交到版本库（仓库 `.gitignore` 已忽略该目录）。
